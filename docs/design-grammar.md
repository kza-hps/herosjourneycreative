# Hero’s Journey Creative — Design Grammar

This document is the source of truth for the visual design pass.

The current repo UI is only a scaffold. Do not treat the current layout, spacing, colours, or components as final design.

---

## Design Vision & Themes

* **Core Concept**: Cinematic creative studio meets workshop house.
* **Paradigm Shift**: The site must move away from a standard product store or software landing page layout, shifting toward a curated creative studio, narrative story house, and public story archive.
* **Brand Colors**: 
  - Main: Black (`#000000`) & Warm White (`#f7f3ea`)
  - Accent: Hero Yellow (`#ffb700`)
  - Support: Charcoal (`#333333`), Aged Gold (`#a87f11`), Blue (`#06358e`)

## Key Visual Directives

* **Typography**: Needs premium typographic layouts (contrast between classical serif and clean monospace/sans-serif).
* **Atmosphere**: Needs space, cinematic breathing room, structured grids, and subtle border lines rather than loud blocks.
* **Tone**: Human, archival, professional, and slightly mystical.
* **Source Material**: The main source materials for the design pass are `/public/brand` and this file (`docs/design-grammar.md`).
